## 2025-02-28 - [Avoid N+1 Stat Calls with os.scandir]
**Learning:** Using `pathlib.Path.iterdir()` combined with `.stat().st_mtime` to sort files by modification time leads to N+1 system calls (one for reading the directory and N for stat). `os.scandir()` caches file attributes, making it significantly faster for this operation (~50% faster in a directory of 100 files). This is a codebase-specific performance pattern to watch for, especially when dealing with many files.
**Action:** Use `os.scandir()` instead of `iterdir()` when iterating over directories and immediately accessing file attributes like `st_mtime`.
## 2025-03-02 - [Avoid N+1 Stat Calls with os.scandir in agent_brain_local]
**Learning:** Using `pathlib.Path.glob()` and sorting by `os.path.getmtime` on the resulting paths results in an N+1 stat call bottleneck (one for glob filtering and one for `getmtime` per file). `os.scandir()` caches file attributes (like `st_mtime` and `is_file()`), avoiding this bottleneck when sorting recent items. This pattern is essential for high-throughput batch operations processing UGC output files.
**Action:** Replace `.glob("*.png")` + `os.path.getmtime` sorting combos with `os.scandir()` and `entry.stat().st_mtime` when retrieving the most recent generated assets. Wrap the block in `try...except OSError` as `scandir` doesn't fail silently like `glob` if the directory is missing.
