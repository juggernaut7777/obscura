## 2025-02-28 - [Avoid N+1 Stat Calls with os.scandir]
**Learning:** Using `pathlib.Path.iterdir()` or `glob()` combined with `.stat().st_size` (or `.st_mtime`) to filter/sort files by attributes leads to N+1 system calls (one for reading the directory and N for stat). `os.scandir()` caches file attributes, making it significantly faster for this operation. This is a codebase-specific performance pattern to watch for, especially when dealing with many files.
**Action:** Use `os.scandir()` instead of `iterdir()` or `glob()` when iterating over directories and immediately accessing file attributes like `st_size` or `st_mtime`.
