## 2024-03-24 - [CRITICAL] Command Injection via `os.system`
**Vulnerability:** User input (`prompt`, `script`, `refs`) was concatenated directly into a shell command string and passed to `os.system(cmd)` in `goal2_sourcing_engine/start_engine.py` (menu choice 10). This allowed for critical command injection, where an attacker could input shell metacharacters (e.g., `; rm -rf /`) to execute arbitrary commands on the host machine.
**Learning:** `os.system` executes commands in a subshell, making it inherently vulnerable to injection when dealing with unsanitized user inputs. Even basic interactive CLI scripts must validate or safely parameterize input. Additionally, variables representing space-separated values must be properly split when transitioned to a safe argument list to avoid being treated as a single literal string argument by subprocess.
**Prevention:** Always use `subprocess.run(args_list)` with a list of arguments instead of a single string. This avoids invoking a shell, ensuring that user inputs are safely passed as arguments to the executable rather than being parsed as commands by a shell.
