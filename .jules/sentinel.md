## 2024-11-20 - [Command Injection via `child_process.exec` in Storefront API Routes]
**Vulnerability:** Command Injection vulnerabilities were found in `storefront/src/app/api/admin/orders/route.js`, `storefront/src/app/api/checkout/route.js`, and `storefront/src/app/api/admin/upload/route.js`. The application used `child_process.exec` to run Python backend scripts, dynamically concatenating unsanitized user input (such as `orderId`, `tracking`, and `pipeline`) into shell commands. This allowed attackers to inject shell metacharacters and execute arbitrary code on the server.
**Learning:** The use of `exec` with string interpolation for passing arguments is inherently dangerous in Node.js because it executes the command via a shell (`/bin/sh` or `cmd.exe`), which interprets metacharacters like `;`, `&&`, and `|`.
**Prevention:** Always use `child_process.execFile` (or `spawn`) when executing external scripts or binaries. `execFile` passes arguments directly to the executable as an array, bypassing the shell entirely and preventing any injected commands from being interpreted.
