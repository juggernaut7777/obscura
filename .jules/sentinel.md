## 2026-07-21 - [Command Injection via os.system]\n**Vulnerability:** User inputs (prompt, script, refs) were directly concatenated into a shell string and executed via `os.system()` in `start_engine.py`, allowing arbitrary shell commands to run if a malicious input was provided.\n**Learning:** The shell natively handles space-separated strings, so substituting `os.system` with `subprocess.run` can break space-separated arguments (like file paths) unless explicitly split using `.split()`. Furthermore, missing files with `subprocess.run` raise exceptions (unlike `os.system` which just logs an error), requiring a try-except wrapper for parity.\n**Prevention:** Always use `subprocess.run` with a list of arguments (never `shell=True`). For multiple files, extend the list with the output of `.split()`, and wrap in error handling blocks to avoid script crashes.
